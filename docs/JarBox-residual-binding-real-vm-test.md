# Actual MiniJVM binding preflight test

The previous modeled-layout test is extended to actual Java frames and VM field metadata. The fixture builds minimal LCDUI/Canvas and delegate classes (no game bytecode). It derives only the three synthetic callsite PCs with javap; the production wrapper always uses Nick's fixed PCs 58/30/5. The exact same C predicate runs at Class_hii.k1 method entry inside real MiniJVM. Both independently owned VMs execute 1000 eligible and 9000 rejected calls, setting the expected result before every invocation. Gate requires zero per-call mismatches; counts alone are not sufficient. Reject offscreen/direct call, null wrapper, owned context, pixel-dependent/headless Graphics, explicit buffer, different context, wrong current Canvas and mutated wrapper link. System.gc runs periodically. No residual optimization, graphics discard, or iOS activation occurs in this fixture. No JIT in host build. No claims about real game, renderer, concurrency inside a draw region or device CPU.
