# Closed draw-region residual: eliminate the wrapper, not just the raster

The experimental host engine adds two liveness policies. Resolved primitive reads are removable only after ordinary VM linkage and class initialization, with exact symbolic field identity, matching loader, correct primitive width/storage and no volatile flag. The value of a live read is still loaded by the original handler. The synthetic oracle warms one ordinary invocation, leaves one cold CP entry and marks a different field volatile. The C plan must match the independent Python plan; the original fixture and residual run in separate VMs. Local read-only declaration inventory on exact Nick t5: 14 plain primitive fields; assuming every eligible read has linked, 482 -> 429 residual nodes (101 -> 48 static read sites). This is an upper-bound static model, not real runtime admission or CPU. Reference reads are still roots.

Closed-draw policy 3 proves that each removed invokevirtual is in a single-entry straight-line argument region starting at an empty-stack aload_0 checkpoint. It rejects internal branches, external stores, intervening helper calls, orphan invokes and incoming edges into the middle. All array faults, division/remainder, static reads and writes stay roots. Checkpoints remain live even when the receiver computation otherwise dies. The host fixture's drawRegion has an actual pure sink branch; a retained m3 effect turns off the sink between regions. The reference executes every original wrapper, the candidate skips whole admitted draw regions, then continues original bytecode with real coordinates on scope closure. Null wrappers and null Graphics are rejected before admission. Compare exact visible calls (image IDs and all eight coordinates), faults, final map state; require actual skips and continuations with separate VM counters. This is not the earlier dummy-coordinate wrapper strategy.

Important boundary: structural closed regions alone do NOT prove absence of class initialization, volatile accesses, aliasing, receiver mutation or native effects. Before iOS admission, exact archive/API method identity, all effectful operands in the region being prelinked, actual rooted Canvas/delegate/Graphics scope and stable ownership under the paint lock must be established. Current executor is still host-only, iOS default unchanged. No game archive rewritten, no JIT or tick changes, no CPU claim. No device test yet.

The closed-region checkpoint now also rejects a cold/unresolved static access before entering the region. The host fixture's cold class initializer actually closes the sink inside argument evaluation; the engine must resume original code before the initializer, and verify one cold deopt with the exact visible draw and class-init trace. This is an additional host gate, not a production stability proof.
