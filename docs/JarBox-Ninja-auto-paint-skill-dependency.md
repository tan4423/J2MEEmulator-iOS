- Class_hda.j() update calls n1 at PCs2001/2005 (one extra call for selected skills); calls ez.a() PC2047 if nonnull. Class_hac.a() invokes character j at PCs699/828/840/2261.

## Original Ninja 2.5.1 confirms shared architecture
- bp.a(t) PC1440 increments cV:I, immediately before 'loi paint charskill' handler. PC20 also assigns cV. bp.b(n,int) PC12 resets cV. bp.J() PCs81/199 reset cV, PC149 checks completion, PCs273/351 compare cV against N-N/3; conditional calls dq.r() PC289 and bp.n() PC364. bp update calls J at PCs1956/1960. This matching producer/consumer pattern is present in the unmodified original game, not a Nick-specific assumption. No need to rely on obfuscated names alone.

## Rare-path candidates (separate from proven paint dependency)
- Class_hoi.v7(Class_hx) death branch PCs262–436 checks aa/o, starts death observation, waits1200ms before recovery calls; special clone branch immediate; Class_hy.dangOnDinhNhanVatSauDoiKhu() uses2500ms stabilization, y5 updates map/zone and timestamps. Main-character branch PCs459–531 waits3000ms before recovery. Class_hoi.f6(Z) resets state and switches active strategy. Class_hbi.z must be traced to this recovery path; do not claim all auto calls pass through it.
- Class_hdd.v7 -> Class_hbd.q() checks explicit state s/r. State1 timeout after5000ms; state2 after5000ms sets state3 and reports waiting for response or relogin. Auto worker may be alive but gate false. Only relevant when that feature is active.
- Auto exception swallowing and ordinary runtime synchronization/GC/network issues remain alternative explanations for intermittent stalls. No assertion of what happened during the historical incident without matching state evidence.

## Residual design consequence
Keep automatic whole-paint skip quarantined. Treat character skill counters, effect initialization, target-associated state, and dependent reads/calls as mandatory observable effects in whole-loop analysis. Preserve original per-paint order and cadence, including conditional/offscreen paths; do not substitute an independent timer, increment s6/cV artificially, send synthetic packets, or rewrite JAR. Specialize map/background work separately where safe, then construct character residual with exact control-flow and effects. Whole-paint skip cannot be authorized solely by a short Canvas delegate or steady-state auto test. Tests must include skill sequences crossing the exact threshold, target invalidation, death/revival/map changes, actual queue effects, separate equivalent VM states, STOP/GC and wake. Static findings are necessary not sufficient for runtime authorization. No build requested for this research checkpoint.
