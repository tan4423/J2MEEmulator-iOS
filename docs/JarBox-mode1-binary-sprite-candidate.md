Mode8 successor goal remains under 10% single-owner total process CPU without lost game effects. E3 scoped sink regressed. Do not reactivate mode8, skip a whole paint or change game JAR/tick/network. Instead accelerate actual sprite raster on mode1. Runtime separately verifies full immutable premultiplied source: alpha exactly 0 with zero RGB or 255, maximum 1,048,576 stored pixels. Partial-alpha, invalid source, rotation, mutable/offscreen, unusual geometry or other modes use original path. Compatible Canvas only after existing queue drain, TRANS_NONE, integer clipped rect, max 65,536 sprite pixels. Source/dest distinct. Opaque rows use memcpy; mixed binary alpha selects whole BGRA word, clear leaves destination. No crop object or CG transform/draw on accepted ordinary fast path. All game Java calls, rendering order, state, owner handles, queries, flush and wake remain unchanged.

Reference result kept on all checks; mismatch or noncanonical CTM/data layout sticky-rejects Canvas. Per-image classification/verification and Canvas counters are owner-local; existing immutable shared pixels remain read-only. No additional timers. Counts in Flight Recorder distinguish fast operations, CG checks and mismatches (also layout rejection).
