# Bounded decoded primitive tier and event-driven long sleep

Both experiments are off by default until CI and iOS validation. The existing combined candidate flag opts in to both, plus the two previous constant fusions. The IPA profile stamp distinguishes all four switches.

- Decoded Interpreter: decode eligible static int-only straight-line methods at original-code conversion, once per VM method, into a pointer-free 64-bit plan. Only up to four integer parameters, eight operand slots, and eleven five-bit micro-ops (immediates reduce the limit). No heap access, branches, allocation, native calls, synchronized methods, exception handlers, or non-int signatures. Existing exact primitive leaf wins. Class initialization, debugger, stop/suspend, JIT-off and stack capacity gates remain. No mutation of game JAR or shared mutable metadata.
- Compact Stack: the decoded tier uses a local uint32_t[8] operand scratch, not the existing 16-byte Java StackEntry. The Java frame, reference lane, JNI and GC root contract remain unchanged. This is a primitive-only pilot, not a general compact JVM stack. No GC can be entered inside the bounded plan. Eight extra bytes per CodeAttribute only when the experiment is compiled in.
- Event-driven Runtime: Thread.sleep of 500..INT32_MAX ms uses a per-call, stack-owned waiter and targeted stop/interrupt wake, with monotonic deadline on iOS. Short sleeps, monitor semantics, GC blocking markers, exception propagation and ordinary wakeup remain separate. Failure returns to the legacy sleep path with remaining duration. One additional pointer per Java thread only when enabled. No altered tick rate or sleep truncation on normal timeout. Actual iOS wait and performance are not yet verified.

Local host checks: production headers, GCC/Clang strict C11, Clang ASan+UBSan: 100,000 decoded expression batches plus random rejection inputs, and 100 batches of actual pthread targeted wake, pre-registration interrupt and spurious-signal deadline checks. Waiter publication and VM layout are modeled; Linux native condition path tested, Apple relative wait still requires CI. No full interpreter/GC integration or game measurements yet. CI at parent remains queued. Do not treat this as a completed device release.
