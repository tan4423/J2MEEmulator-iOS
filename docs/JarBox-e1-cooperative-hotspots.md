# E1 cooperative method/backedge hotspot pilot

Build switch JARBOX_HOTSPOT_DIAG=1; independent off control. Default on for the next combined diagnostic IPA. No JIT, JAR change, runtime effect elision, timer, Mach suspend or per-opcode hook. Checkpoints at execute_method_impl entry (including before existing fast paths), and existing check_gc_pause for negative branch offsets. Not all interpreter paths/backedges are covered; direct fast paths, native execution, GC, main thread and long straight-line code may be underrepresented. Every 256 checkpoints check mode 1, debugger/stop/suspend, then read current thread CPU clock. Limit one accepted opportunity per 10ms thread CPU, no catch-up; initial opportunity sets deadline. Actual rate may be much lower; clock-check overhead not zero. A long native interval can be attributed to the following checkpoint rather than native work. These are **cooperative hotspot observations**, not unbiased CPU samples, inclusive method time or execution counts. No logic progression claim. No unsafe stack walk. PC is last observed converted bytecode target (UINT32_MAX = entry/unknown), not histogram or original JAR offset proof. Scope 1 is observed E2 paint scope, 2 outside observed scope (not game logic proof), 0 E2 disabled. Scope transition can be missed. Identity is escaped class/name/descriptor; identical names in different classloaders merge within one VM, long names rejected. No Java values, pointers or packet contents.

64-row per-owner Space-Saving table (approximately 11 KiB; fixed even when off), nonblocking trylock. Every accepted observation adds one to total; evicted minimum count becomes error of new identity. For each displayed row, true accepted count in [count-error,count], not a CPU percentage. Top six cumulative rows only; cannot subtract top rows across snapshots to compute window counts. Busy writer drops and invalid clock/name counters separate; busy reader returns hot_ok=0, not valid zero. Snapshot inside existing session callback lease, copies identities before return, no metadata retained. Export hot_rows grammar: count:error:last_pc:scope:escaped_class~escaped_method~escaped_descriptor, rows separated by |; delimiters percent-encoded. Counter reads for drops can race. No change to existing E2/region-stage fields. No overhead estimate until matched off control. Logs may rotate sooner with added bounded rows.

Host: exact header and fixture GCC/Clang -Wall -Wextra -Werror, ASan+UBSan passed 20,000 heavy hitter/noise notes, clock gating, owner isolation, escaped delimiters, invalid key, busy report, 160,000 attempts from 8 pthreads. Separate Swift Linux C-import smoke test for fixed 1280 byte buffer and withUnsafePointer read passed (not actual UIKit build). Source wiring test in CI. Full iOS build and device data pending. E1 native PC/time profiler and E3 automatic same-session A/B/A are still not implemented. No new CPU savings claim.
