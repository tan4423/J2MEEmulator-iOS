# Compatible mode-1 sprite crop candidate and stage measurement

E2 device baseline: 7.26% crop hits, ~20.7k misses/s. This justifies a bounded experiment, not a claim that crop creation dominates. V2 uses 128 entries, 32 sets x 4 ways, round-robin replacement on insertion; same nominal 1 MiB per Canvas including metadata, exact source pointer+rectangle match, retained source identities once per distinct image plus conservative stride*height and overhead charge per crop. No new cross-VM state. Budget/creation failure returns original CG crop without changing cache. No change to renderer eligibility, clip, transform, draw order, mutable images, offscreen, JAR, tick, or JIT. Source lookup on miss scans at most 128 identities; conflict/budget admission can still regress and reject a useful crop. This is logical accounting, not measured physical RSS. Old cache preserved by switch JARBOX_CROP_CACHE_V2=0.

Independent JARBOX_REGION_STAGE_DIAG=1: one in each 128 compatible nonculled region tails, rotating position per Canvas. No extra timer or suspend. Includes direct calls reaching same renderer. Three thread CPU clock reads only for selected calls. Hit/miss group duration includes snapshot retain, lookup/create, replay capture check and full image release; draw group measures treo_draw_region_cg (transform/state/CG draw inclusive), excludes final releases, handle acquisition, earlier queues/barriers/cull, and actual deferred raster outside call. Not pure crop creation vs raster. Invalid clocks/failed snapshots/crops excluded and counted. Sampled subset only; other native E2 fields unchanged, do not add nested times. Flush publishes cumulative owner counters; nontransactional snapshots and unflushed tail may differ. Compare samples/seen, hit_samples/samples, hit_ns/hit_samples, miss_ns/(samples-hit_samples), draw_ns/samples. Do not scale into process CPU without matched conditions; no CPU saving claim. Both switches independently stamped, default on candidate, legacy/off control remains; other experimental switches unchanged.

Host GCC/Clang and ASan+UBSan passed exact candidate header against CG reference-count doubles: 40,000 collision accesses (39,996 hits), 100,000 mixed accesses with injection, budget/reference/owner invariants. Synthetic not actual game/CG pixels. Region helper 100,000 blocks and invalid clock checks passed same compilers/sanitizers. Linux cannot build iOS; full suite and device pending. E1 and E3 still open. No request to install this intermediate candidate until a useful combined measurement checkpoint.
