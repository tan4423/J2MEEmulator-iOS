# Session-owned sockets and Java Socket API

Baseline 1ae9e95 (TrungDucTV intermittent server version rejection remains open). On explicit Close Tab/Close Game, stop transport for the pinned owner before waiting for Java. Parking/switching tabs is unchanged. Registry tracks actual POSIX fd creations for TCP/UDP bind, accept, connect and TLS; scopes borrow a live session and the one-way network_stopping latch rejects late sockets. Shutdown wakes connected peers; close orphan descriptors only after workers, callbacks and GC finalizers have drained. Ordinary close removes registry record and invalidates context under the same lock. TLS wrap uses a separately owned duplicated fd to prevent double close of a reused integer. Connect uses cancellable nonblocking poll, preserves original flags, shares a real TCP timeout across candidate addresses after DNS. DNS resolution itself remains blocking; no established socket during DNS. Remote server logout/cache delay remains outside emulator control.

Java Socket patch implements connect(endpoint, timeout), half shutdown, TCP_NODELAY, strict InputStream EOF/timeout/error, complete output writes, stream close, available and range checks. Preserve GCF legacy return codes. Fix native endpoint lookup errors and network-byte-order ports; TLS bounds and failed transport cleanup. Codemagic compiles against bundled boot JAR, checks existing accessible ABI and packaged bytes. HTTP URLConnection timeouts are NOT implemented here: GCF/TLS layered timeout propagation still needs work; do not add no-op methods. No game changes, protocol rewriting or session-limit changes. Native fixture and actual CI/device verification are separate.

Regression checks: local socketpair owner isolation, peer EOF, late fd admission, TLS dup, idempotent close, orphan drain, actual NODELAY option, strict read contract and boot ABI checks.

Follow-up source review fixed the prior 1ae9e95 compile defect: array element type is `Instance.mb.arr_type_index`, not a direct Instance field. Updated the String fixture to mirror the real layout. Previous CI returned Xcode status 65; detailed compiler output was not accessible, so other failure causes are not excluded. Keep registry lock out of potentially lingering close, preserve legacy reuseaddr constants, and store pre-connect Java timeout and NODELAY options until a real connection exists.
