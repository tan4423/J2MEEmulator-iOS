# Original-PC continuation at empty-stack draw boundaries

The 7036a8c host CI passed the native compiler and both previous fixture policies. The next prerequisite is a non-replaying exit from residual execution when the sink scope ends. This commit adds a host-only checkpoint policy, not a live iOS admission.

For the bounded k1 opcode subset, mark original aload_0 draw entries only if the incoming operand stack is empty and all three int locals are definitely initialized. Treat those locals as liveness roots at every checkpoint. Independently generate the same plan via Python. Retain all field reads/writes, throwing arithmetic, arrays and method calls. The current prototype uses one residual prefix and an original bytecode suffix. When the simulated scope ends, before the next checkpoint's first operation, clear added slots, restore the original frame size and stack pointer, disable residual dispatch for that frame, and continue at the original PC. Do not restart or run any effects twice. Nonempty-stack or uninitialized-local checkpoints reject the plan.

New host residual_resume suite uses the original fixture class in both VMs. Before a deterministic per-invocation limit (0..3 successful wrapper calls), the controlled Graphics sink ignores primitive coordinates. After the limit, it records all eight coordinates of each call in exact order. Compare full output records, final fields, exception class and source image order, including all subsequent coordinates; require actual admissions and nonzero but not universal mid-method continuations. The reference VM never uses residual. Existing no-op and wrapper-aware differentials remain in CI.
