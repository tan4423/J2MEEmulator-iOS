# Stateful whole-loop residual (r2 shape, host only)

The exact Nick t5 r2 method has 391 bytecodes, 746 bytes, stack 7, locals 5. The 35 virtual calls include 28 wrapper calls, of which 12 set color, translate or clip; the rest include collection accessors, casts, image size helpers and Integer.intValue. Class_hyg.l (PC10 and PC720) reads current translation, reverses it and sets clip. Do not omit either state reset. List traversal can throw or synchronize; keeping the draw-only result does not make such effects dead.

Policy 5 extends the existing whole-CFG liveness compiler to keep arbitrary category-1 calls with full typed operand reconstruction at their original PCs. It handles instance field reads, reference/int arrays, casts, reference branches, reference locals 2/4, integer constants, shifts and negation. No field read with a nullable receiver or array/cast check is erased. The only removable draws are explicitly classified wrapper signatures in closed single-entry argument regions with no intervening stores, calls or branches. State calls remain original effects with every argument; unsupported draw regions remain original calls. The whole method is sliced using CFG liveness, not a replacement of every Graphics operation with a no-op. On scope loss resume original PC with exact initialized locals including reference local4. The two-VM host gate compares final game state, Graphics state, collection/logic call counts, exception category and every visible draw coordinate/state after fallback. No arbitrary JAR is authorized. The actual r2 path is not activated on iOS by policy 5. Existing k1/i3 compiler policies retain their accepted opcode subsets and independent plan oracles. No claim about device CPU or full render-tree coverage.
