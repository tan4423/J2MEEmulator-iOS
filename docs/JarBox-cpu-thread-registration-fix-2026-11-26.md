# CPU incident — symbolicated from exact original IPA

Build c09a0ddb8f108291380a22741c19880aa7b3bc7a; Mach-O UUID 6E97E363-10EC-3F54-897B-DE54DA920959 exactly matches the iOS report. Image-relative offsets resolve to runMIDlet/startGame worker → jvm_bridge_run_midlet_for_token → call_main → call_method → execute_method → execute_method_impl → java_lang_Thread_start → jthread_start (+0x2e4) → arraylist_push_back (+0x2c/+0x34/+0x40), thrd_current. No line DWARF or captured lock owner; the worker's token is unknown.

Source has a concrete circular wait: GC holds thread_list while waiting for a Java parent's suspension acknowledgement; the parent spins in arraylist_push_back during Thread.start, never reaching a safepoint. A separate publication gap lets GC suspend a snapshot then wait for newly inserted threads not in that snapshot. Thread status NEW/ZOMBIE was checked only before the GC wait, so an exiting worker could strand it. These are actionable runtime defects, not proof of the exact lock owner in the original report.

Fix: only contended Thread.start registration cooperates with GC and sleeps 1ms after a failed trylock, before publishing child state. Hold list lock across registration/native pthread creation/rollback, handle list allocation failure, preserve worker lease. GC requests suspension and awaits acknowledgements under the same list lock; resume traversal also serialized. Recheck exit/STOP on every GC wait and abandon collection after 2s observed elapsed (or 2000 waits safety fallback), using existing abort path that resumes world without mark/sweep. No unconditional game sleep, no JAR edits, no cross-VM state, no JIT. The change can raise GC abort frequency on slow devices; monitor before considering stable. Other unrelated lock-order risks and uncooperative native paths are not certified fixed.

Host test forces the list/GC acknowledgement contention, timeout, exit and STOP using extracted production helper bodies with pthread doubles. The actual miniJVM/iOS integration and original intermittent reproduction remain to be verified.
