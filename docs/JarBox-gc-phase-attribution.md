# GC worker phase attribution (post-E3)

E3 actual device result: scoped sink increased total CPU by 2.30 points despite paint savings. GC worker CPU/cycle increased from ~7.3–7.5 ms to 20.7 ms with similar cycle frequency. This does not establish which GC stage, allocation rate or clock/frequency change caused the difference.

Independent JARBOX_GC_PHASE_DIAG=1 (default on in diagnostic build; 0 compiles out boundary calls). Existing collector worker lends one stack-only cycle record via thread-local pointer, clears pointer immediately on return; terminal synchronous cleanup is not included. Seven boundaries, each two clocks (thread CPU and raw monotonic wall). No per-object clocks or locks, new timers, GC period, root/sweep algorithm, heap limit, JAR, JIT, gameplay or scheduling change. Six inclusive intervals: pause (VM share lock and stop-world acknowledgement/object moves), roots (temporary-list splice/root snapshot), mark (mark counter and graph search), resume (resume and unlock), deferred (finalization processing), sweep (scan/destruction, accounting and optional squeeze). Instrumentation adds clock cost, including while world stopped. CPU and wall clocks not sampled atomically. Wall includes waiting and descheduling, not CPU or exact game pause duration. Scan/reclaimed/bytes reuse existing sweep locals; not allocations or all finalization effects. Only completed valid collections enter coherent per-owner cumulative totals. Aborts, invalid clocks, busy writer and unavailable reader separately recorded; no partial collection data, no waits on snapshot. Drop counts are separately atomic, not transactional with totals. Metrics include all modes; use stable endpoint windows; a cycle straddling endpoint may be included in full. Compare phase cycles to existing gc_cycles, never blindly add GC phase CPU to gc_ns. No change to full raster default or previous E3 conclusion. No CPU benefit claim.

Host GCC/Clang and ASan+UBSan ran exact header and fixture: 100,000 successful publications, 80,000 concurrent attempts from four writers, 100,000 reader attempts, coherent totals, isolation, invalid/abort/busy cases. Synthetic clocks, not actual collector performance. Full integration and iOS CI pending; no IPA install requested.
