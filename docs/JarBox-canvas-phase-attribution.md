# Mode-1 Canvas scoped CPU attribution

E3 showed Java worker minus measured paint increasing by ~8.62 percentage points with scoped sink. That residual is not direct game logic CPU. This pilot isolates a larger existing Canvas interval without changing Java/JAR, render path, or scheduling. Build switch JARBOX_CANVAS_PHASE_DIAG=1, independent of E1/E2/GC and Core; 0 compiles it out. Existing beginAfkPaint and endAfkPaint calls bracket the scope (after begin's existing key lookup and before end's native return). Reuse the exact negative-stamp CPU time at profilePaintBegin and CPU timestamp at profilePaintEnd. Only two new CPU-clock reads per ordinary eligible outer frame. Pre includes remaining begin/native return, Graphics.reset and work before inner stamp. Paint matches existing inner CPU interval. Post includes profile-end diagnostics after its timestamp, Java flush and native end housekeeping. Excludes Canvas admission, earlier lock wait, final result notification and Java state reset after endAfkPaint, and other work outside scope. Not whole doPaint, not logic or pure raster, CPU only (not wall or gameplay progress).

Thread-local numeric immutable session token with existing native key check on begin/end. No VM metadata pointer retained. Matched nonnested mode-1 scopes only; nested, incomplete, backwards clocks and observed end-mode mismatch dropped. Owner change clears local state without charging either VM; an unpaired end cannot recover missing historical data, and unobserved transitions may pass. No locks in Java game logic; publish uses a nonblocking trylock after end housekeeping, coherent snapshot or invalid reader. Counters cumulative, separately read invalid/busy; validate frame coverage against existing paint calls, tolerate only explicitly explained endpoint races. Do not subtract unlike frame sets or sum overlapping Java/paint CPU. No actual CPU savings claimed; full raster remains default. Core ABA remains off.

Host GCC/Clang and ASan+UBSan passed exact helper and fixture (100,000 valid timing scopes plus nested/malformed/mode/owner/busy rejection). Synthetic timestamps only; not UIKit integration or real device benchmark. Source wiring fixture added, full CI pending. No install requested.
