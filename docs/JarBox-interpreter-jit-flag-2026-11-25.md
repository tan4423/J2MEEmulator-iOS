# Interpreter JIT flag hot path

Baseline df5c5c0. Remove the external function call for the three interpreter JIT gates (integer/reference leaf and regular method execution), using the same relaxed atomic load directly in the header. Keep the public getter/setter ABI and the actual JIT enable state unchanged; no JIT activation, no cached per-VM policy, no changes to gameplay or renderer. Disabled builds return constant zero. No new diagnostics or timer. Existing leaf guard tests retain the same condition using the inline accessor. Host tests exercise enabled and disabled configurations; actual iOS build and CPU comparison pending. This is a small housekeeping optimization, not evidence of a large CPU reduction. Do not add a speculative virtual method cache until class unload and concurrent cache mutation are audited.
