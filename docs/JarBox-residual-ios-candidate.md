# Isolated iOS residual candidate — first real execution bridge

At f814c1a full host CI passed, including the closed-region test: B=1929 admissions, 1769 continuations, 1872 guarded draw-region entries and exactly one cold-class continuation. A=0 for all native counters. This is synthetic fixture evidence, not iOS gameplay.

This change wires the existing slot executor into an isolated, default-off iOS build flag TREO_RESIDUAL_EXPERIMENT. It requires the existing paired Core Canvas sink, not mode 8 or whole-paint skip. It recognizes only the two byte-identical-class Nick t5 archives; other games remain compatible. The build recipe generates SHA256 identities of the exact patched bundled boot/API jars, and the bridge verifies those plus the exact game archive before arming. The first real plan additionally checks the exact converted k1 and wrapper code SHA256 (1368 and 67 bytes, independently extracted from both local Nick jars), actual final delegate/Canvas/Graphics ancestry, wrapper field and method metadata, no handlers/monitor/JIT/debugger, stack capacity and initialized region fields. No eager resolution or class initialization. If any region is cold, the entire invocation stays original until naturally warmed. Native plan and count live in the owner CodeAttribute; freed with class teardown. At each checkpoint the paired scope serial, owner, parked mode and wrapper Graphics link must still match. Loss of scope resumes the original PC without replay. An unexpected internal executor invariant does not abort the iOS process: it quarantines the owner and takes the VM's error unwind path. This is not an approved recovery from a correctness fault, and is a candidate blocker if observed.

The build is explicitly experimental, not default, and still only covers k1. Original JAR bytes and gameplay cadence unchanged. No machine code generation. The certificate assumes the launch JAR and bundled files remain unchanged for that owner (current loader contract); exact classfile hash at load and alias/concurrency proof across every method remain future gates. Rooted scratch reference slots may extend lifetime within a frame. Full-tree residual, actual device admission frequency, screen pixel dependencies, host/iOS compilation/regression, STOP/wake and CPU benefit remain to be verified. Do not install merely because it packages.

New CI recipe configuration residual enables only the paired Core + residual path (all unrelated experimental flags and heavy render observers off). It stamps residual-1 and verifies build provenance. Normal build retains residual-0. No device request until the new gates pass.
