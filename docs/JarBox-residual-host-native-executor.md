# Residual host-native executor: original PCs and ordinary effect handlers

Primary target Nicknsonet, then TrungDucTV and V9, with original Ninja as reference. The prior bytecode bridge passed actual two-MiniJVM CI on f57402e. This step executes a generated pointer-free plan on the original fixture method, not a rewritten class. It is strictly host-only (compilation into iOS/JIT configuration is rejected). No production Treo mode, JAR, game logic, GC cadence or iOS flags changed.

- tools/ninja_residual_native.py emits one node per retained typed IR op, with original PC, typed slot operands, two successor indexes and effect opcode/length. The little-endian expected converted code includes all original instruction bytes and CP operands. Generated locally for synthetic fixture (49 nodes) and exact Nick k1 (412 nodes). No proprietary files committed.
- jarbox_residual_plan.h executes pure operations on VM StackEntry slots using the corrected Java integer arithmetic. Structural/type validation before entry. No new field access or exception implementations.
- interpreter.c only when JARBOX_HOST_RESIDUAL_TEST is defined: opt-in per VM; known fixture name/descriptor/shape, exact converted bytecode copy, nonnull receiver, stack capacity, no handler/sync/debug/stop. Reserve 28 slots in ordinary VM stack; initialize them; references are real GC roots (may extend lifetime until frame exit). Run pure nodes directly; materialize operands only at a retained effect and enter existing original bytecode handler at original PC. In-place quickening retries retain operands; completed effects transfer result to typed slot. No re-execution of original method after an effect. Unsupported plan/continuation in this test build aborts the test, not an iOS fallback policy. Explicit suspend/stop checks at pure nodes; no JIT generation in host stub. Exact CP/API/receiver and lifetime proof for live games remains open.
- run.sh residual now runs both prior original-vs-generated-bytecode and original-vs-native-plan gates. In the second both VMs load the original fixture; A=0/B=2000 admissions required, plus exact 2000 outcome records. Optional JARBOX_RESIDUAL_ARCHIVE=path (exact prior Nick SHA only) runs the same host suite with actual k1 fixture. Local generator and standalone C mock control test compiled; real native integration requires new CI. No CPU claim. Local mock test does not verify VM handlers/GC.
- Real wrapper effects, screen/pixel dependencies, mode and owner admission, original exception/GC/debug/stop/wake parity, ordered effects, production lifetime and CPU remain gates. No device build requested.

Run: bash tools/host_multivm_smoke/run.sh asan 1 residual. For trusted local Nick corpus, set JARBOX_RESIDUAL_ARCHIVE before running. Do not ship generated fixture classes or host executor.
