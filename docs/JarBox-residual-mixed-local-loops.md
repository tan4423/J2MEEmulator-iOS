# Whole-loop compiler extension for mixed local types

Nick Class_hii.i3 is 218 bytecodes, 413 bytes, 5 locals, five draw sites and an actual putstatic t2 at PC324. The first nested loop uses local 3 as Image, the second uses it as an integer tile; local 4 is a loop induction variable. A residual must retain original field writes, q3 calls (including their exception behavior), array faults and both local types when continuing to the original PC. r2 is more complex: it uses translation/clip/color state, virtual getters and additional callees; do not treat all wrapper calls as sinks.

New compiler policy 4 adds mixed local3 typing with definite initialization at CFG merges, explicit reference moves/null, a separate slot for local4, unary and binary integer branches, and a second closed sink signature (Image,III). Checkpoint liveness preserves all definitely initialized ordinary locals; local4 is copied back before clearing scratch on fallback. Existing modes retain their strict old accepted opcode subset. The executor can handle the new primitive read widths with original handlers. The extended test uses two real MiniJVMs with identical original synthetic class, no rewritten game JAR. It has ordered visible image/coordinate traces, state t2, exception cases, GC, and scope ending from retained q3 calls. Test requires nonvacuous actual skips and original-PC continuations. No i3 live admission yet: actual caller/paint ancestry and exact two wrapper/API method identities remain necessary. Normal iOS remains off.
